Song Party

Local Wi-Fi Multiplayer AI Party Game

  • Designed and shipped a Jackbox-style, real-time multiplayer web game supporting simultaneous local-network play across an arbitrary number of phones and a shared host display, using Node.js, Express, and WebSockets.
  • Architected a server-driven game state machine coordinating a multi-phase round lifecycle (lobby → prompt → answer collection → AI content generation → synchronized playback) with automatic reconnection handling for dropped clients.
  • Integrated the Anthropic Claude API to dynamically generate creative prompts and transform crowdsourced player input into structured, genre-specific song lyrics in real time.
  • Built a dependency-free procedural audio synthesis engine in pure Node.js — custom oscillators, WAV encoding, and genre-tuned chord/tempo presets — generating original instrumental tracks with zero third-party audio APIs or paid services.
  • Solved cross-device synchronized media playback using scheduled wall-clock timestamps and browser autoplay-policy workarounds, delivering consistent audio start times across every connected device.
  • Designed the system for graceful degradation: full offline fallback (prompt bank + template lyrics generator) keeps the game fully playable with zero API keys configured.
  • Managed the feature through a standard GitHub PR workflow (branch, PR, review, merge) into a live production site.
Node.js Express WebSocket (ws) Anthropic Claude API Procedural Audio Synthesis Real-time State Sync Git/GitHub

AI Simulation Game

Interactive NPC Simulation with Claude-Powered Dialogue

Live Demo
  • Built a browser-based simulation game from scratch — HTML/CSS front end driving a real-time JS game loop with animated agents moving through a scene.
  • Designed a proximity-triggered dialogue system: agents generate contextual conversation when they approach specific scene landmarks, using landmark identity to shape the prompt sent to the LLM.

Autonomous Email Management Agent
